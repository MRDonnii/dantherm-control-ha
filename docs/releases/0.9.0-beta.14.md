# Dantherm Control til Home Assistant 0.9.0-beta.14

Ændringer siden 0.9.0-beta.13. Denne beta er en ren kompatibilitetsrettelse til Home Assistant's nye enhedsregister og ændrer ikke styringen.

## Rettet

Home Assistant 2026.8 knytter hver enhed til én integrationspost og har udfaset det globale opslag `device_registry.async_get_device(identifiers=...)`. Det fjernes i Home Assistant 2027.8. Integrationen brugte det ved opstart til at finde hovedenheden (`hch5_mk1_hac1`) og Pi-controlleren (`hch5_pi_controller`), så eksisterende enheder kan beholde deres navne. Det gav en deprecation-advarsel i loggen.

- Enhedsopslagene bruger nu `async_get_device_by_identifier(identifier, entry_id)` og slår kun op inden for integrationens egen post. Advarslen forsvinder dermed.
- På Home Assistant før 2026.8, hvor den nye metode ikke findes, bruges det hidtidige opslag stadig. Integrationen understøtter fortsat Home Assistant fra 2025.8.
- Opslaget ligger i en lille hjælper (`device_lookup.py`). Der er ingen andre brug af `async_get_device` i integrationen.

## Installation og kompatibilitet

I HACS: åbn Dantherm Control, vis betaversioner via **Redownload / Download igen**, og vælg **0.9.0-beta.14**. Genstart derefter Home Assistant. Release-assetet `hch_passivelink-0.9.0-beta.14.zip` kan alternativt pakkes ud i HA-konfigurationsmappen ved manuel installation.

- **Genstart Home Assistant** efter installationen, så de ændrede Python-moduler indlæses.
- Kræver ingen ny Pi-version. Pi 1.13.0-beta.1 og ældre versioner fungerer som med 0.9.0-beta.13.
- Identifikatorer, enhedsnavne, entity-ID'er, unique IDs, rumtilknytninger, controllerindstillinger og dashboards bevares. Ingen konfigurationsmigrering er nødvendig.
- Den eksisterende indirekte HAC1-eftervarmestyring, timing og frostbeskyttelse bevares.

## Validering

Nye tests dækker begge veje (ny metode findes / findes ikke), to integrationsposter hvis opslag holder sig til egen post, og genindlæsning uden dublerede enheder og med bevarede navne. En test kører desuden hjælperen mod Home Assistant's rigtige `DeviceRegistry`. Hele suiten består lokalt med 179 integrationstests og fire HA-tests.
