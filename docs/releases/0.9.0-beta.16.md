# Dantherm Control til Home Assistant 0.9.0-beta.16

Ændringer siden 0.9.0-beta.15. Denne beta viser eftervarmens model, forudsigelse og ydelse som sensorer, på samme måde som Better Thermostat gør for radiatorventilerne. Ændret af Claude AI.

## Nyt

Sensorerne ligger på Pi-controllerens enhed (kategori Diagnose) og læser blokken `afterheat_ha` fra Pi 1.13.0-beta.11:

| Sensor | Enhed |
|---|---|
| Eftervarme styringsmetode (årsagen står i attributten `hvorfor`) | tekst |
| Eftervarme modelstatus (Lærer / Klar / Usikker) | tekst |
| Eftervarme forudsagt luft om 1 min / om 10 min / laveste forudsagte luft | °C |
| Eftervarme forudsigelsesfejl | K |
| Eftervarme varme pr. trin | K |
| Eftervarme reaktionstid op / ned / forsinkelse | s |
| Eftervarme rettelse | K |
| Eftervarme effekt | kW |
| Eftervarme energi i dag (samlet, nulstilles ved midnat; kan bruges i energioversigten) | kWh |
| Eftervarme tid under bund 24 t | % |
| Eftervarme middelafvigelse 24 t | K |
| Eftervarme skift pr. time 24 t | skift/t |

- En sensor er utilgængelig, mens Pi'en ikke har en værdi for den (fx før modellen har lært noget).
- Mod en ældre Pi uden blokken oprettes ingen af sensorerne, og der kommer ingen fejl.
- Kun aflæsning; styringen er uændret. Navnet "Eftervarme styringsmetode" er valgt, fordi "Eftervarme styring" allerede bruges af sensoren med Pi'ens beskrivelse.

## Installation og kompatibilitet

I HACS: vis betaversioner via **Redownload / Download igen**, og vælg **0.9.0-beta.16**. Genstart derefter Home Assistant. Kræver Pi 1.13.0-beta.11 for at få værdier.
